# Agent Lab Rules (carried into this repo)

## Purpose

IMS13 Yearbook - production web app built via the phased execution strategy in
`BUILD-PLAN.md` (agent-lab workspace).

## Rules

- Never delete files without approval.
- Never push directly to main.
- Explain large changes before making them.
- Run tests before declaring a task complete.
- Prefer small, reversible changes.
- Do not introduce new dependencies without justification.
- Never let the Builder deploy or push to main.
- Never expose secrets to agents unnecessarily.
- Every phase ends with a verifiable Definition of Done (see BUILD-PLAN.md).

## Workflow

1. Understand
2. Plan
3. Implement
4. Test
5. Review
6. Report
